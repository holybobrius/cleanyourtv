# Quiet Graphite

A minimal, low-overhead home screen for Xiaomi MiTV-MOEU1:

- wallpaper with a dark readable scrim and no ambient effects;
- one horizontally scrolling row: larger 16:9 app cards, a consistent small gap, and no second row peeking up;
- a subtle card outline at rest and a light halo around the focused card;
- a compact, single-line date; a quiet greeting; icon-only controls with a smaller clock;
- the app library remains in the top bar.

The star-trails photo in `wallpaper.jpg` is by Daniel D on Unsplash:
https://unsplash.com/photos/a-mountain-range-with-stars-in-the-sky-MmykLHdm8W0

It is deliberately a theme rather than a launcher fork: it can be changed or removed with
`tools\theme.ps1 --reset` after the launcher is installed. The dock order can be changed through the
launcher UI without rebuilding.
